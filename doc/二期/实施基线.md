# 二期中转站与用量看板

需求来源：下载目录 2026-09-24 二期 HTML 原型包及 2026-09-25《部门与个人限额逻辑说明》。两个 Token 看板 HTML 完全相同，合并为一个页面。

## 已确认规则

- 上游仅 OpenAI、Google；原型其他供应商是示例，不在新增接入范围。
- 限额和并发只在 Sub2API 执行；其他供应商直连工具不扣公共池、不受中转额度耗尽影响。
- 一个员工对应一个中转用户，客户端与工作台内部两个用途 Key 共用个人额度和并发。
- 普通员工继承主部门所属一级部门的个人限额、并发，同时占用部门池；独立员工只受个人额度限制。
- 切换类型及主部门后按当前归属重算整月公共池，个人已用不清零。业务报表保留发生时部门。
- 达限停止新请求，允许在途请求完成；不支持超额自动降级。
- 北京时间自然月；使用中转权威 Token 计量，图片、积分分列。
- 员工只能读取授权的自身业务输入产出；网关完整审计正文和导出仅超级管理员，访问审计、加密存储、保留 180 天。
- 配置必须经中转确认才显示已生效；上游无真实指标时显示不可用，不把百分比伪装为 Token 容量。

## 实施验证

后端：`cd backend && mvn test`；前端：`cd frontend && npm test && npm run build`。
真实环境及回归脚本只在隔离测试环境执行。完整制品必须由源码提交构建；本次开发不直接发布生产。

中转扩展、真实配置生效及端到端用量必须分别验证；工作台单元测试不能替代中转执行验收。

## 2026-09-28 开发验证记录

已实现部门/独立配额、并发、员工中转身份与双用途 Key、原生准入扩展、用量同步与对账、权限隔离和加密审计；原型中的配额页、用量看板、员工详情、个人数据、账号编辑及窗口阈值已接入实际后端接口。其他供应商直连继续独立计量，不受中转限额影响。

本地验证结果：

- 工作台后端：从发布提交导出的干净目录执行 `mvn -q test`，124 项通过，0 失败、0 错误；覆盖部门切换、独立配额回算、幂等同步、权限、Key 生命周期及告警去重解除。此前工作目录统计的 127 项包含 3 项旧报告，发布验收以干净构建结果为准。
- 前端 `npm test`：179 项通过；`npm run build` 成功；原生控件检查脚本通过。构建仍有第三方注释与 bundle 大小提示。
- 固定上游源码加扩展：PostgreSQL 配额生命周期、异步记账与租约、策略版本冲突、审计加密和窗口阈值测试通过，`make build` 生成完整服务制品。
- Chrome 本地页面验证了配额保存、同步失败提示、员工详情和 365 天热力图空态；未配置原生连接时不显示配置已生效。

用户明确同意并授权后，已仅在本地隔离实例提交 `v2026.06.10` 合规确认。原生 Sub2API、PostgreSQL、Redis 和工作台实际 HTTP 接口已完成以下联调；供应商一端使用本地确定性协议服务，固定返回 20 输入 + 10 输出 Tokens，不消耗真实供应商额度：

- 工作台自动创建原生员工身份、内部 Key；通过个人接口创建客户端 Key；策略返回已生效。
- 客户端和工作台工具调用经过原生网关并产生原生用量记录，同步后合计 3 次、90 Tokens；内部调用正确关联运行记录和项目。
- 客户端请求占据唯一并发时，内部请求被拦截；在途请求正常完成。
- 将个人额度设为已用量 90 后，客户端返回 `429 PERSONAL_QUOTA_EXHAUSTED`，内部调用返回明确限额错误；Google 原生 API Key 入口也验证了同一员工额度拦截。
- 超级管理员成功读取、导出两种 Key 对应的完整审计；权限隔离另由工作台集成测试覆盖。
- 客户端 Key 轮换后旧 Key 返回 401；吊销后内部 Key 仍可正常调用。
- 中转额度设为 0 时，同一工具改用独立直连配置仍可调用，确认限额只作用于中转站。

联调发现并修复了部门数据源错配：中转配额原先读取旧 `sys_department` 种子目录，现改为组织管理实际维护的 `organization_department`，排除已删除部门。新增跨组织管理、员工主部门编辑、配额查询的集成测试，验证子部门继承、主部门切换及实际额度一致性。

本次未调用真实 OpenAI / Google 服务，真实模型能力、账号窗口指标及目标流量压测仍属于环境验收项。没有部署生产。后续已按完整源码提交和制品完成测试服发布，结果见 [测试发布验收](测试发布验收.md)。扩展边界与联调前置见 [中转扩展说明](../../integrations/sub2api-workbench/README.md)。
