## 原型示例与已确认业务约束

- 限额仅作用于中转站，不改变其他供应商直连行为。
- 上游新增接入仅 OpenAI、Google；其他供应商示例不引入。
- 不实现超额自动降级；原型中的下拉位置保留已确认的暂停规则。
- 真实窗口百分比不能转换为 Token 容量；缺失容量不照搬示例数字。2026-11-06 确认以正常调度且有有效窗口读数的 OpenAI 订阅账号为样本，分别展示 5 小时和 7 天剩余百分比的算术平均及样本数，并标注“仅供参考”；无有效读数时显示暂无数据。
- Token 消耗看板的部门列表只展示所选时段内 Token 消耗大于零的部门，按消耗量降序排列，每页 5 个；切换时段后返回第一页。工具排行保持原有展示方式。
- 首页“赋能部门”按累计成功 AI 调用的部门去重统计：工作台调用按用户当前主部门归属，中转调用使用记录中的部门归属；下级部门归并到仍启用的一级部门。没有成功调用的启用部门不计入。
- 客户端 Key 统一由后台“用户管理”按用户生成、轮换或吊销；“我的数据”不再提供自助入口和接口。管理员弹窗展示当前站点的 OpenAI 兼容与 Gemini Base URL 并可复制；新 Key 只展示一次，由管理员通过安全渠道交付用户。生成或轮换要求账号启用且中转身份就绪，旧 Key 在轮换后立即失效。
- 原型热力图的随机数据不能进入正式页面。日期按北京时间，星期与月份坐标对应真实日期。
- 原始网关审计仍只对超级管理员开放；业务结果沿用既有权限校验。

## 2026-09-29 账号接入补正

再次核对原型发现新增账号流程漏掉 API Key 接入及窗口阈值，之前账号列表的还原结论不能代表接入弹窗完成。

- 新增与编辑复用统一表单，按原型的账号标识、平台/优先级双列、凭证方式/凭证区域、并发/双窗口三列排列；弹窗宽度 540px、圆角 24px、页眉/正文/页脚间距单独限定，不改变旧功能或白色共用侧栏。
- 仅支持已确认的 OpenAI / Gemini，均可选择 OAuth 订阅或官方 API Key。API Key 不限制为 OpenAI 的 sk 前缀；编辑留空不覆盖原密钥，非空更新且不回显。
- 订阅路径保留授权链接复制和回填；Google 提供 Google One 和 Code Assist 类型。原型单行 Session Token 输入按真实授权流程展开，不将浏览器 Cookie 当作通用订阅凭据。
- OpenAI 订阅创建时写入 5h/7Day 阈值（默认 90/95）；账号、阈值和调度分组一起提交。Gemini/API 无对应订阅指标时显示不适用，员工限额继续执行。
- 代理和备注作为实际接入所需补充字段。密钥只转发到中转后端，不写操作日志，错误响应不回显提交凭证。
- 官方 API 账号使用平台官方地址，不增加第三方兼容地址范围。
- 账号测试支持填写该账号可用的模型名称；留空仍沿用已启用的同平台中转文本模型，避免 Gemini/API 账号测试依赖修改工作台默认模型。
