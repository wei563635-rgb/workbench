# 开发任务拆解

## P0 必做任务

| 任务 | 输入 | 输出 | 验收标准 |
|---|---|---|---|
| 上传数据 | Excel / CSV | fileId | 文件可上传并保存 |
| 读取表头 | fileId | sheets / columns | 能展示所有 sheet 和列 |
| 自动识别字段 | columns | suggestedMapping | 能识别 question / answer |
| 人工确认映射 | mapping | mappingId | 用户可手动选择字段 |
| 数据清洗 | raw data | rawDetails | 保留原始 question / answer |
| 大模型分析 | rawDetails | analysisJson | 输出标准 JSON |
| Schema 校验 | analysisJson | validation | 不合规能拦截 |
| JSON 质检 | analysisJson | score / correctedJson | 低质量结果能拦截或修正 |
| HTML 注入 | JSON + template | HTML | dashboard-data 内嵌完整 |
| 在线预览 | HTML | preview | 页面可查看 |
| 下载 HTML | dashboardId | html file | 断网可打开 |
| 错误提示 | errors | message | 用户能理解问题 |
