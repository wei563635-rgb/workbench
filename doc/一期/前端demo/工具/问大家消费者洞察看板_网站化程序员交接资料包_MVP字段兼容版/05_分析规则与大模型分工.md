# 分析规则与大模型分工

## 1. 总流程

```text
读取问大家数据
↓
字段映射
↓
数据清洗
↓
生成 rawDetails
↓
调用大模型分析
↓
生成标准 JSON
↓
Schema 校验
↓
质检 Prompt 校验
↓
修正 JSON
↓
注入 HTML 母版
```

## 2. 程序负责

```text
文件上传
字段识别
字段映射
空值处理
重复处理
数据类型转换
原始明细保留
生成 cleanData / rawDetails
JSON Schema 校验
HTML 数据内嵌校验
单文件 HTML 导出
```

## 3. 大模型负责

```text
消费者问题语义理解
问题聚类
关注点识别
购买阻力判断
人群 / 场景 / 角色识别
消费者核心决策点排序
主图 / 推广图表达方向生成
推广图测图矩阵生成
详情页证据链生成
FAQ / 客服兜底问题识别
```

## 4. 关键分析规则

| 规则 | 要求 |
|---|---|
| 明细保留 | details 必须保留原始 question / answer |
| 关注点归纳 | 不能只做关键词统计，要识别消费者决策点 |
| 人群识别 | 必须来自真实问题信号，不能凭空画像 |
| 测图矩阵 | 必须有样本依据、测试理由、表达方向、画面方向 |
| 详情页证据链 | 必须有为什么、数据依据、承接方式、代表问题 |
| 文案边界 | 输出表达方向，不直接输出最终广告文案 |
| 样本说明 | 问大家样本占比不能写成真实购买人群占比 |

## 5. 禁止低质量方案

```text
禁止只用关键词匹配替代语义分析
禁止只做简单统计后套模板
禁止只做一次模型调用后直接出最终看板
禁止没有质检就进入模板渲染
禁止让前端直接读取 Excel 作为最终数据源
```
