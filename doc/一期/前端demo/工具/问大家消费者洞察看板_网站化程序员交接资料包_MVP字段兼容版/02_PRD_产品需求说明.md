# PRD：问大家消费者洞察与推广图测图策略看板

## 1. 工具名称

问大家消费者洞察与推广图测图策略看板生成工具

## 2. 业务背景

运营团队需要通过问大家数据快速理解消费者真实疑问，包括：

```text
消费者核心关注点
不同人群 / 场景的关注差异
主图 / 推广图测试方向
详情页优化证据链
FAQ / 客服兜底问题
```

目前人工用 AI 分析可以生成高质量看板，但复用成本高，因此需要网站化工具。

## 3. 使用人群

| 角色 | 使用目的 |
|---|---|
| 运营 | 上传问大家数据，查看消费者洞察 |
| 推广 | 参考测图矩阵安排素材测试 |
| 设计 / 文案 | 根据表达方向产出推广图和详情页内容 |
| 运营负责人 | 查看核心决策点和优化方向 |

## 4. 用户流程

```text
进入页面
↓
选择“问大家消费者洞察看板”
↓
上传问大家数据源
↓
系统自动识别字段
↓
用户确认 question / answer 字段
↓
点击生成看板
↓
系统调用大模型分析
↓
查看分析结果
↓
下载 HTML / 导出数据 / 复制方向
```

## 5. 核心功能

```text
文件上传
字段识别
字段映射确认
数据清洗
大模型分析
标准 JSON 生成
JSON 质检
HTML 模板渲染
在线预览
HTML 下载
```

## 6. 非核心功能

```text
黄金样例库
复杂权限
多人协作
模板后台
历史版本对比
投放数据回填
```

## 7. 不做什么

```text
不重新设计最终版看板
不做自由拖拽 BI
不做复杂报表平台
不让前端直接读取原始 Excel 作为最终数据源
第一版不开发黄金样例库
```

## 8. 最终交付结果

```text
用户上传问大家数据源后，系统生成在线可查看、可下载的单文件 HTML 看板。
```
