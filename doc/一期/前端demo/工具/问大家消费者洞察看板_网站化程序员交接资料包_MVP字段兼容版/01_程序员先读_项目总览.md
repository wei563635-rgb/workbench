# 程序员先读：问大家消费者洞察与推广图测图策略看板 网站化项目总览

## 1. 项目目标

开发一个公司内部使用的问大家看板生成工具。业务同事上传不同格式的问大家数据源后，系统自动识别字段、清洗数据、调用大模型分析，并套用最终确认版 HTML 母版生成同款看板。

## 2. 用户最小操作流程

```text
进入网站
↓
上传问大家 Excel / CSV
↓
系统自动识别“消费者问题”和“他人回答”
↓
用户确认字段映射
↓
点击生成看板
↓
系统调用大模型分析
↓
在线预览看板
↓
下载单文件 HTML
```

## 3. 第一版 MVP 必须实现

```text
上传数据
读取表头
自动识别 question / answer
人工确认字段映射
清洗数据
调用大模型分析
生成标准 JSON
JSON Schema 校验
JSON 质检 Prompt 校验
注入 HTML 母版
在线预览
下载 HTML
错误提示
```

## 4. 第一版不做

```text
黄金样例库
复杂权限系统
多人协作
历史版本对比
模板管理后台
投放数据回填
多租户系统
复杂日志看板
```

## 5. 核心技术原则

```text
页面不重新设计
前端不直接读 Excel
后端 / 大模型先生成标准 JSON
前端只读标准 JSON 渲染
最终 HTML 必须完整内嵌 dashboard-data
```

## 6. 大模型和程序分工

程序负责：

```text
文件解析、字段识别、字段映射、数据清洗、JSON Schema 校验、HTML 注入和导出。
```

大模型负责：

```text
消费者语义理解、关注点归纳、人群/场景识别、测图方向、详情页证据链等分析判断。
```

## 7. 程序员不要做什么

```text
不要重新设计页面
不要用关键词分类替代大模型分析
不要只生成页面壳子
不要让导出的 HTML 依赖外部 CSV / JSON
不要删除最终确认版看板中的核心模块和交互
```
