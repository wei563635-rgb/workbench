# 腾讯云服务器上线说明

这套项目当前最适合按静态网站上线，不需要先搭后端服务。

## 最省事的方式

如果你已经能 SSH 登录腾讯云服务器，优先用这套：

1. 本地执行上传脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\upload-site.ps1 -Server 你的公网IP -User root
```

2. 登录服务器后解压并执行一键部署：

```bash
unzip -o /var/www/wendajia-dashboard-src.zip -d /var/www/wendajia-dashboard-src
sudo bash /var/www/wendajia-dashboard-src/deploy/install-static-site.sh "_"
```

如果你有域名，把上面最后的 `"_"` 改成：

```bash
sudo bash /var/www/wendajia-dashboard-src/deploy/install-static-site.sh "your-domain.com www.your-domain.com"
```

## 适用前提

- 当前看板页面已经是单文件 HTML，可直接被 Nginx 托管。
- 默认入口文件是根目录的 `index.html`，它会自动跳转到 `16_V31最终HTML样式参考.html`。
- 如果你后面生成了新的最终 HTML，只需要替换 `index.html` 跳转目标，或者直接把新的文件名改成更稳定的英文名。

## 上线前你先确认两件事

1. 你的腾讯云服务器是 Linux CVM，并且你能用 `root` 或有 `sudo` 权限的账号登录。
2. 如果服务器在中国大陆，想通过域名访问，域名需要先完成备案；如果暂时没备案，可以先用公网 IP 测试访问。

## 推荐目录结构

把整个项目上传到服务器的这个目录：

```bash
/var/www/wendajia-dashboard
```

至少保留这些文件：

```text
index.html
16_V31最终HTML样式参考.html
15_V31参数化HTML母版_强制内嵌数据校验版.html
deploy/nginx-wendajia.conf.example
```

## Ubuntu 服务器部署步骤

### 1. 安装 Nginx

```bash
sudo apt update
sudo apt install -y nginx
```

### 2. 上传站点文件

你可以本地压缩后再传：

```bash
zip -r wendajia-dashboard.zip .
```

服务器上解压到网站目录：

```bash
sudo mkdir -p /var/www/wendajia-dashboard
sudo unzip wendajia-dashboard.zip -d /var/www/wendajia-dashboard
```

也可以直接用我准备好的上传脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\upload-site.ps1 -Server 你的公网IP -User root
```

### 3. 配置 Nginx

如果你想省掉手工配 Nginx，可以直接在服务器执行：

```bash
sudo bash /var/www/wendajia-dashboard-src/deploy/install-static-site.sh "_"
```

有域名时改成：

```bash
sudo bash /var/www/wendajia-dashboard-src/deploy/install-static-site.sh "your-domain.com www.your-domain.com"
```

复制示例配置：

```bash
sudo cp /var/www/wendajia-dashboard/deploy/nginx-wendajia.conf.example /etc/nginx/sites-available/wendajia.conf
```

把配置里的 `your-domain.com` 改成你的域名，把 `root` 保持为：

```text
/var/www/wendajia-dashboard
```

然后启用站点：

```bash
sudo ln -sf /etc/nginx/sites-available/wendajia.conf /etc/nginx/sites-enabled/wendajia.conf
sudo nginx -t
sudo systemctl reload nginx
```

### 4. 放行防火墙和腾讯云安全组

服务器系统层面：

```bash
sudo ufw allow 80
sudo ufw allow 443
```

腾讯云控制台里还要确认 CVM 安全组已经放行：

- `TCP:80`
- `TCP:443`
- 如果你用 SSH 登录，还要保留 `TCP:22`

### 5. 访问测试

浏览器打开：

```text
http://你的公网IP
```

或：

```text
http://你的域名
```

如果能看到看板首页，说明静态站已经成功上线。

## 绑定 HTTPS

建议上线后再补 HTTPS，常见做法有两种：

- 用腾讯云证书服务申请免费证书，再挂到 Nginx。
- 用 `certbot` 为 Nginx 申请 Let's Encrypt 证书。

如果你需要，我可以下一步直接继续帮你生成一份 HTTPS 版 Nginx 配置。

## 以后怎么更新内容

如果只是换新一期看板，不需要改服务器程序，通常只做这几步：

1. 把新的最终 HTML 上传到 `/var/www/wendajia-dashboard`
2. 用它替换原有看板文件，或者改 `index.html` 的跳转地址
3. 刷新浏览器检查页面

## 常见问题

### 打开只有目录列表或 404

通常是 Nginx 的 `root` 没指向 `/var/www/wendajia-dashboard`，或者 `index.html` 没上传完整。

### 页面样式乱了

当前这份最终看板是内嵌样式版本，正常不应该因为外部资源丢失而乱样式。如果乱了，通常是文件传输时损坏，重新上传即可。

### 域名打不开但 IP 能打开

通常优先检查：

- 域名解析是否指向这台腾讯云服务器公网 IP
- 中国大陆服务器的域名是否已备案
- 腾讯云安全组 80/443 是否放行
