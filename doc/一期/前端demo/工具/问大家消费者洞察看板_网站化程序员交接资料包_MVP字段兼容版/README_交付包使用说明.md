# 交付包使用说明

本资料包用于开发「问大家消费者洞察与推广图测图策略看板」网站化 MVP。

## 程序员建议阅读顺序

```text
00_逻辑合理性与工程可实施性验证.md
01_程序员先读_项目总览.md
02_PRD_产品需求说明.md
03_输入数据规范与字段映射.md
04_标准JSON_Schema.json
05_分析规则与大模型分工.md
06_前端模板复刻与HTML导出规范.md
07_大模型分析Prompt.md
08_JSON质检Prompt.md
09_API接口说明.md
10_技术架构与部署方案.md
11_开发任务拆解.md
12_测试用例与验收清单.md
13_最终HTML母版说明.md
14_样例JSON_结构示例.json
```

## 第一版目标

```text
用户上传问大家数据源后，只要能确认 question 和 answer 两个字段，就可以生成 V31 / 最终版样式的数据看板。
```

## 关键约束

```text
页面不重做
字段兼容 question / answer
大模型负责分析
Schema 负责结构稳定
质检 Prompt 负责质量拦截
HTML 母版负责样式复刻
最终 HTML 必须完整内嵌数据
```
