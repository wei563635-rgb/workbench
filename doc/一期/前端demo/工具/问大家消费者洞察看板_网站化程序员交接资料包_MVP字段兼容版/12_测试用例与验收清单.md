# 测试用例与验收清单

## 1. 测试用例

| 用例 | 输入 | 预期结果 |
|---|---|---|
| 标准问大家数据上传 | 含 question / answer | 成功生成看板 |
| 字段名不同 | “用户问题”“买家回答” | 自动识别并提示确认 |
| 自动识别失败 | 非标准表头 | 用户可手动选择 |
| 缺少 question | 只有回答 | 阻断生成 |
| 缺少 answer | 只有问题 | 阻断或要求确认 |
| question / answer 都为空 | 空行 | 清洗删除 |
| question 有值 answer 为空 | 未回答问题 | 保留并标记 |
| 空文件 | 空 Excel | 提示无有效数据 |
| 错误格式 | PDF / 图片 | 提示格式不支持 |
| 重复数据 | 完全重复行 | 去重或提示 |
| 超大文件 | 超限制 | 提示或分批处理 |
| 大模型失败 | API 异常 | 重试或提示 |
| Schema 失败 | JSON 缺字段 | 自动修正或阻断 |
| 质检不通过 | 空泛结论 | 自动修正或待复核 |
| HTML 下载 | 成功看板 | 下载单文件 HTML |
| 离线打开 | 断网打开 HTML | 页面可用 |

## 2. 验收清单

### 字段与数据

- [ ] question / answer 字段识别准确
- [ ] 字段映射可人工确认
- [ ] 缺少 question / answer 时阻断生成
- [ ] details 保留原始问题和回答
- [ ] 清洗规则可解释

### 分析质量

- [ ] JSON 符合 Schema
- [ ] 大模型分析结论有样本依据
- [ ] 测图矩阵有样本数据和测试理由
- [ ] 详情页证据链可追溯原始问题
- [ ] 质检不通过能自动修正或提示

### 页面与导出

- [ ] 页面与最终满意版一致
- [ ] 下钻 / 筛选 / tab / 明细追溯正常
- [ ] HTML 完整内嵌 dashboard-data
- [ ] HTML 不依赖外部 CSV / JSON
- [ ] 断网可打开
