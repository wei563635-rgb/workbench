# 部署与验收

## 本地部署

```bash
cp .env.example .env
# 填入 OPENAI_API_KEY
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## Docker 部署

```bash
cp .env.example .env
docker compose up --build
```

## 验收用例

1. 上传 `samples/sample_input.csv`；
2. 自动识别“消费者问题”和“他人回答”；
3. 确认字段后生成；
4. 任务状态正常推进；
5. 生成 JSON 能通过 Schema；
6. 生成 HTML 能在线打开；
7. 下载 HTML 后断网可打开；
8. HTML 中存在完整 `dashboard-data`；
9. 看板保留 V31 页面结构和交互。
