# 工程可实施性验证

## 结论

本包的 MVP 架构可实施，适合先在公司内网或单台云服务器试运行。

## 核心闭环

```text
文件上传
→ 字段识别
→ 人工确认
→ 数据清洗
→ 大模型分析
→ JSON 校验
→ 业务质检
→ HTML 注入
→ 预览与下载
```

## 已验证的工程条件

- Excel / CSV 解析有成熟库支持；
- 字段别名匹配与人工映射可实现；
- 大模型 API 可返回 JSON；
- 本地 JSON Schema 可校验；
- 最终 HTML 已包含 `dashboard-data`；
- HTML 可以通过替换 JSON 生成单文件结果；
- FastAPI、Docker 均适合 MVP 部署。

## 当前风险

1. 大文件可能超过模型上下文；
2. 大模型分析质量受模型、Prompt 和数据质量影响；
3. 当前后台任务保存在文件中，生产环境建议更换任务队列和数据库；
4. 当前字段识别是规则和相似度匹配，必须保留人工确认；
5. 当前默认使用 JSON mode，并通过本地 Schema 校验和修复保障结构。

## 上线前建议

- 用真实数据跑通至少 3 次；
- 人工核对核心关注点、人群分类、测图矩阵和详情页证据链；
- 确认 V31 模板和 Schema 字段一致；
- 配置 API 调用额度和错误日志；
- 正式多人使用前接入数据库和权限。
