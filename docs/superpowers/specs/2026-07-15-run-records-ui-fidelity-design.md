# 运行记录页高还原设计

## 目标

以 `doc/一期/前端demo/一起互动AI工作台/运行记录页面.html` 和用户提供的截图为视觉基准，重做工作台运行记录列表，使页面层级、筛选栏、表头、独立记录行、信息密度和操作按钮接近设计稿，同时保留已确认的现行业务规则。

## 业务边界

- 仅展示已完成的成功、失败工具运行记录。
- 筛选项保留工具、员工、所属部门和状态。
- 不恢复“关联状态”筛选。
- 不恢复关联或重新关联项目操作。
- 操作列仅提供真实可执行的查看详情、复制结果和下载附件。
- 分页继续使用现有真实运行记录数据与分页逻辑。

## 页面结构

1. 去除运行记录页标题和说明区，主内容顶部直接展示筛选栏。
2. 筛选栏使用白色圆角容器，搜索框在左，筛选标签与控件横向排列。
3. 列表移除外层白色大卡片，表头直接显示在页面背景上。
4. 每条运行记录作为独立白色圆角行，记录之间保留明显纵向间距。
5. 分页位于列表下方右侧，空状态占据完整列表宽度。

## 列表信息

- 时间：日期和时间分两行显示。
- 记录类型：使用紫色小型矩形徽标。
- 工具名称：展示工具色块图标、名称和输出摘要；失败摘要使用红色。
- 员工：展示姓名首字头像和姓名。
- 所属部门：使用低饱和色块标签。
- 资源消耗：主值和耗时分两行展示。
- 所属项目：显示真实项目名，无项目显示 `-`。
- 状态：使用绿/红状态点和成功/失败文字。
- 操作：使用紧凑图标按钮，并提供悬停提示。

## 操作显隐

- 查看详情：所有记录显示。
- 复制结果：存在输出摘要或有效输出数据时显示。
- 下载附件：存在至少一个可下载附件时显示。
- 不可用操作不显示，不使用禁用按钮占位。

## 交互动效

- 记录行悬停采用 A1 方案：整体上浮 `3px`，阴影增强，并显示浅紫边框。
- 动画时长 `180ms`，使用 `ease` 曲线。
- 动画只使用 `transform`、`box-shadow` 和 `border-color`，不改变尺寸和布局。
- 在 `prefers-reduced-motion: reduce` 下取消位移和过渡动画。
- 图标按钮悬停切换为品牌紫背景和白色图标。

## 响应式约束

- 桌面端固定各列的稳定比例，工具名称列获得最大弹性空间。
- 较窄桌面和移动端使用横向滚动，不压缩到文字逐字换行。
- 行高、头像、徽标和按钮尺寸固定，动态内容不能引起布局位移。
- 长摘要单行省略，完整内容在详情抽屉查看。

## 实现边界

- 沿用现有 Vue 数据、筛选、分页和详情抽屉逻辑。
- 仅重构运行记录模板和专属样式，不修改项目、看板或后台页面。
- 操作按钮调用现有附件提取逻辑；复制结果新增轻量前端操作，不新增后端接口。
- 图标优先使用项目已有组件能力；不为本页面单独引入大型 UI 依赖。

## 错误处理

- 复制失败时使用现有通知组件提示。
- 附件窗口被浏览器拦截或下载地址无效时展示可读错误。
- 无记录时显示明确空状态，不渲染空白行卡片。

## 验收标准

- 页面结构与设计稿一致：顶部筛选、背景表头、独立圆角记录行、图标操作。
- 不出现关联状态筛选或关联项目按钮。
- 成功、失败、无项目、无资源、无附件和长摘要均无错位。
- 悬停动效符合 A1 方案，且减少动态效果设置生效。
- 查看、复制、附件下载和分页行为可用。
- 前端回归测试与生产构建通过。
