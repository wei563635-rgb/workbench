# AI 工作台问题修复设计

## 目标

以 `doc/一期/前端demo/一起互动AI工作台` 为前台视觉和交互基准，修复问题表中的后台基础管理、项目页面、独立项目看板和运行记录问题。所有统计必须来自真实业务数据，不保留演示计数或前端模拟。

## 范围

### 后台基础管理

- 后台品牌名称改为“管理后台”，总 Token 指标改为“总 Token 消耗”。
- 用户创建和编辑均支持角色多选、组织树部门多选和主部门单选。
- 创建用户成功后关闭表单，展示账号和临时密码，提交期间禁止重复操作。
- 用户支持编辑、重置密码和逻辑删除。
- 部门以树形结构维护，可在任意节点新增下级，并支持编辑、启停和逻辑删除。
- 角色创建和编辑隐藏角色编码与权限编码，只展示中文业务名称；支持逻辑删除。
- 工具状态统一展示中文；模型只保留启停；部署只保留预留入口。
- 后台所有列表采用服务端分页。

### 项目页面

- 左侧项目栏支持名称搜索和部门筛选，第一条可见项目默认选中。
- 新建和编辑项目使用弹窗，字段包括项目名称、商品名称、项目封面、所属部门、品牌、负责人、类目、售价、立项时间和商品卖点。
- 封面支持 JPG、PNG、WebP，单张不超过 5MB，可上传、替换和删除；无封面显示默认占位。
- 项目详情、统计和任务布局遵循 `项目页面.html`。
- 统计包含任务进度、累计产出物、Token 消耗和图片生成数，不显示部门进度标签。
- 任务按工具所属部门分栏。完成任务展示产出摘要、执行员工、时间和查看入口；未完成任务展示执行入口。
- 所有部门任务完成时显示统一完成提示。

### 独立项目看板

- 在通用导航中增加独立“项目看板”页面，不复用“项目管理看板”工具。
- 顶部展示总项目数、总体任务进度、项目产出数、Token 消耗和图片生成数。
- 支持本周、本月和自定义时间范围。
- 支持项目/商品搜索、部门、品牌和创建人筛选。
- 表格字段遵循 `项目看板页面.html`，并使用服务端分页。

### 运行记录

- 一行代表一次已结束的工具运行，只展示成功或失败，不展示访问、打开和进行中记录。
- 支持搜索、员工、员工主部门和执行状态筛选，不提供项目关联状态筛选。
- 表格包含时间、记录类型、工具、员工、主部门、资源消耗、所属项目、状态和操作。
- 详情抽屉展示输入、输出、模型调用、耗时和附件；成功记录支持复制结果或下载附件。
- 所属部门来自用户主部门，历史记录保留运行时员工和部门快照。
- 列表使用服务端分页，默认每页 10 条。

## 数据模型

### 项目统一

停止使用 `project_board` 的演示计数模型。正式项目数据统一使用：

- `project`：项目名称、部门、负责人、状态、立项时间、创建人和逻辑删除字段。
- `project_product`：商品名称、品牌、类目、售价、卖点和封面文件引用。
- `project_member`：项目成员。
- `project_task`：项目任务、工具、执行人、运行和完成时间。
- `project_result`：项目产出快照及移除状态。
- `tool_run`：工具运行主体及员工、部门、项目快照。
- `ai_call_log`：模型调用、Token 和图片结果。
- `file_asset`：项目封面和运行附件元数据。

现有 `project_board` 数据只执行一次迁移，业务代码不再读取或写入该表。

### 逻辑删除

用户、部门和角色增加 `deleted_at`、`deleted_by`。正常查询、选择器、登录和权限计算排除已删除数据；历史项目、运行和审计记录保留原引用与快照。

- 部门存在未删除子部门或有效用户归属时拒绝删除，并返回中文阻断原因。
- 角色仍被有效用户引用时拒绝删除。
- 用户删除后立即禁止登录，但历史数据可继续展示姓名快照。
- 已删除账号和角色编码不允许重新使用。

## 统计口径

- 项目任务进度：已完成任务数除以任务总数；无任务时为 0%。
- 项目产出物：未移除的 `project_result` 数量。
- Token 消耗：项目关联运行下 `ai_call_log.total_tokens` 之和。
- 图片生成数：成功图片调用响应中实际图片项数量之和。
- 项目看板整体数据：在当前用户数据权限和时间筛选范围内聚合项目数据。
- 运行记录资源消耗：按 `run_id` 聚合 Token 和图片数。

## 接口边界

- 项目列表、项目看板和运行记录使用独立的分页查询接口，统一返回 `items/page/pageSize/total/totalPages`。
- 项目创建和编辑使用 multipart：结构化项目字段加可选封面文件；删除封面使用显式布尔字段。
- 删除接口只更新逻辑删除字段，返回被删除对象 ID 和删除时间。
- 业务冲突返回 409，参数错误返回 400，权限错误返回 403；响应只包含中文业务信息，不暴露 SQL。

## 性能与索引

- 项目查询按 `deleted_at/department_id/created_at` 建索引。
- 任务按 `project_id/status/tool_key` 建索引。
- 运行按 `status/user_id/department_id/finished_at` 建索引。
- AI 日志按 `run_id/status/model_type` 建索引。
- 所有列表在数据库侧筛选、排序和分页，前端不加载全量数据。

## 验收与测试

- 后端覆盖逻辑删除、引用阻断、项目 CRUD、封面校验、统计口径、运行筛选和分页。
- 前端覆盖用户防重复提交、组织树、项目默认选中、搜索筛选、项目统计、任务分栏和运行分页。
- 使用设计稿逐页进行桌面和窄屏截图对比，检查文本溢出、控件错位和遮挡。
- 构建完成后在独立端口部署测试环境，执行登录、后台管理、项目创建、工具运行、统计更新和记录查询回归。
